# Sonus 🎧

Sonus is a modular Java-based audio player built using JavaFX MediaPlayer.

The project started as a simple WAV player and evolved into a scalable multi-format media player architecture with playlist management, shuffle/repeat systems, metadata extraction, and MP3 support.

---

# Features

- MP3 playback
- WAV playback
- Playlist system
- Folder loading
- Auto-play next song
- Shuffle mode
- Repeat playlist
- Repeat single song
- Metadata extraction
- Song duration display
- Modular architecture
- JavaFX playback backend


# Technologies Used

- Java
- JavaFX
- jaudiotagger
- IntelliJ IDEA
- Git & GitHub
