🎰 Java Slot Machine

A simple and fun console-based slot machine game built in Java.
The player chooses a difficulty level, sets their starting balance, places bets, spins the slots, and earns payouts based on matching symbols.

Perfect project for beginners learning Java basics like loops, arrays, functions, input handling, and logic.

🚀 Features

Difficulty selection (Easy, Normal, Hard)

Custom starting balance

Betting system

Randomized slot symbols

Payout based on symbol matches

Shows winnings or losses each round

Loop continues until player quits or balance becomes zero

Clean console output with emojis

🧠 What I Learn

This project helps me understand:

User input using Scanner

Random number generation

Arrays and string arrays

Methods (spinRow, printRow, getPayout)

Game loops (while)

Input validation

Conditional logic

A great beginner project for practicing structured Java programming.

🎮 How the Game Works

Choose difficulty

Enter starting balance

Place your bet

Slots spin randomly

Matching symbols give payouts

Play again OR exit

Game ends when the player quits or runs out of money

📂 How to Run

Install Java (JDK 17+ recommended)

Save the file as Main.java

Open a terminal in the project folder

Compile:

javac Main.java


Run:

java Main
